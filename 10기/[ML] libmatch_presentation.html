02 · Problem Statement
읽을 책이 없는 게 아니라,
읽을 책을 못 찾는 것!
공공도서관 이용률과 미이용 사유를 살펴보면 문제의 본질이 드러납니다.

Problem

도서관 이용자는 베스트셀러·사서 추천에 의존해 책을 고르며, 자신의 잠재적 취향에 맞는 새 책을 발견하기 어렵습니다. 미이용 사유 중 "읽을 만한 책이 없어서"가 학생 13.8%에 달합니다.

→
Solution

개인별 대출 이력을 수집하지 않고, 이용자가 선택한 관심 도서 1권을 출발점으로 문맥·키워드·대출 패턴을 결합한 3단 하이브리드 추천을 제공합니다.

→
Effect

이용자는 새로운 도서를 발견하고, 도서관은 추천 결과를 북큐레이션·장서개발 자료로 활용하며, 프라이버시 보존형 추천 모델의 공공기관 확산 가능성을 제시합니다.

05 · System Architecture
3단 하이브리드 추천 모델
문맥, 키워드, 이용 패턴을 각각 다른 알고리즘으로 분석한 뒤 가중 결합합니다.
// Final Recommendation Score
Score = 0.5 × KR-SBERTrank + 0.3 × TF-IDFrank + 0.2 × CFrank
// 문맥 유사도를 중심에 두되, 키워드·이용 패턴으로 보완
α 0.5
KR-SBERT
제목·저자·분류·책소개를 문장 임베딩으로 변환해 코사인 유사도 계산. 표면 단어가 달라도 문맥과 의미가 유사한 도서를 탐색합니다.
β 0.3
TF-IDF
전처리된 텍스트의 핵심 단어를 벡터화해 코사인 유사도 계산. 주요 키워드와 주제가 비슷한 도서를 탐색합니다.
γ 0.2
Item-Item CF
도서관별 인기 대출 순위를 점수로 환산해 도서 간 유사도 계산. 여러 도서관에서 비슷한 인기 양상을 보인 도서를 탐색합니다.
점수 환산 로직
도서관별 순위는 1위 → 30점 ~ 30위 → 1점으로 환산했습니다. 경기도 데이터는 순위만 제공되어 (1001 − 순위) 공식으로 1위를 1,000점으로 환산한 뒤, 서로 다른 척도를 도서명 기준으로 합산했습니다.
전처리 파이프라인
KoNLPy Okt 형태소 분석기로 명사 중심 핵심 단어를 추출하고, 한 글자 단어·특수문자·불용어를 제거했습니다. 이 결과를 TF-IDF 벡터화와 KR-SBERT 임베딩의 입력값으로 사용했습니다.
06 · Development Process
모델 결과를 그대로 믿지 않았다
단일 모델의 편향을 발견하고, 다른 모델로 보완한 실제 검증 사례입니다.
🔍
DISCOVERY
TF-IDF 단독 추천의 표면 단어 편향
『물고기는 존재하지 않는다』를 TF-IDF만으로 추천했을 때, 제목의 "물고기"라는 단어 때문에 어린이 생물 도서가 함께 추천되는 현상이 나타났습니다. 키워드 일치가 곧 주제 일치를 의미하지 않는다는 것을 확인했습니다.
✓
RESOLUTION
KR-SBERT 문맥 임베딩 결합으로 편향 완화
KR-SBERT를 결합하자 철학·교양 분야 도서가 상위로 재배치되며 TF-IDF의 표면 단어 편향이 완화되었습니다. 다만 하위 순위에는 일부 어린이 도서가 남아있어, 데이터 확대와 로직 보완이 필요하다는 한계도 함께 기록했습니다.
🔍
DISCOVERY
서로 다른 척도의 인기도 데이터
도서관별 대출 순위(1~30점)와 경기도 인기 순위(1~1,000위)는 척도 자체가 달라, 단순 합산 시 경기도 데이터의 영향력이 왜곡될 위험이 있었습니다.
✓
RESOLUTION
공통 점수 체계로 통일 후 도서명 기준 합산
(1001 − 순위) 공식으로 경기도 데이터를 1~1,000점 척도로 환산해, 두 데이터를 도서명 기준으로 공정하게 합산할 수 있도록 통일했습니다.

09 · Impact & Limitations
기대효과와 한계
이해관계자별 기대효과와 함께, 프로토타입으로서의 한계를 명확히 밝힙니다.
대상기대 효과
도서관 이용자개인 대출 이력 없이 관심 도서 기반 추천, 새로운 도서 발견, 탐색 시간 단축
사서 및 도서관데이터 기반 북큐레이션, 장서 개발, 희망도서 검토 지원
공공데이터 제공기관공개 데이터의 실질적 활용 확대와 서비스 가치 창출
지역사회독서 접근성 향상과 공공도서관 이용 활성화
분석 대상 도서 수가 제한적이며, 일부 도서는 책 소개가 확보되지 않아 콘텐츠 분석에 충분히 반영되지 못했습니다.
협업 필터링은 개인별 대출 관계가 아닌 도서관 단위 집계 순위를 활용해, 상업 플랫폼 수준의 세밀한 개인화에는 한계가 있습니다.
RMSE·MAE는 협업 필터링 구성요소에 대한 평가로, 하이브리드 추천 전체의 만족도를 직접 의미하지는 않습니다.
향후 도서·지역 데이터 확대, 사용자 만족도 기반 가중치 조정, 실시간 소장 여부 반영이 필요합니다.
